Secure Browsing Checklist for Employees
1. Objective

To help employees use the internet safely, protect company information, and reduce risks such as phishing, malware, and unauthorized access.

2. Website Security
Verify that the website uses HTTPS before entering sensitive information.
Check the domain name for spelling mistakes or suspicious variations.
Never ignore browser security or certificate warnings.
Remember that HTTPS does not guarantee that a website is trustworthy.
3. Safe Downloads
Download files only from trusted websites.
Scan downloaded files using approved security software.
Avoid unexpected email attachments and suspicious installers.
Do not download pirated software or unknown applications.
4. Browser Updates
Enable automatic browser updates when available.
Install security updates promptly.
Restart the browser when required to complete updates.
Use a supported browser version.
5. Browser Extensions
Install extensions only from trusted sources.
Review the permissions requested by each extension.
Remove unnecessary or unfamiliar extensions.
Use extensions approved by the company's IT team.
6. Suspicious Websites and Phishing
Check links before clicking them.
Be cautious of urgent messages requesting passwords or OTPs.
Avoid entering confidential information on suspicious websites.
Report phishing attempts to the IT or security team.
Stop if the browser displays a security warning.
7. Company Information Protection
Use strong, unique passwords.
Enable multifactor authentication (MFA) where available.
Follow company VPN and network security policies.
Avoid saving passwords on shared computers.
Sign out of company accounts when using shared devices.
8. Actions to Take When a Threat Is Detected
Stop interacting with the suspicious website or file.
Do not enter more information or download additional files.
Report the incident to the IT or security team.
Follow the organization's incident-response procedures.
If credentials may have been exposed, notify IT immediately.

10. Conclusion

Following these secure browsing practices helps employees reduce exposure to phishing, malicious downloads, unsafe browser extensions, and outdated browser vulnerabilities.

Employees should remain alert, protect confidential information, and report suspicious online activity promptly.
