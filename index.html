Secure Browsing Practices

A secure browsing checklist for employees to promote safe internet usage and protect company information.

Website Security

  • Verify HTTPS before entering sensitive information.
  • Check website addresses for suspicious spelling.
  • Never ignore browser security warnings.

Safe Downloads

  • Download files from trusted sources.
  • Scan files using approved security software.
  • Avoid suspicious attachments and installers.

Browser Updates

  • Enable automatic updates when available.
  • Install security updates promptly.
  • Use a supported browser version.

Browser Extensions

  • Install trusted and approved extensions.
  • Review extension permissions.
  • Remove unnecessary or unfamiliar extensions.

Suspicious Websites

  • Verify links before clicking.
  • Never enter credentials on suspicious pages.
  • Report phishing attempts to the IT team.

Reminder: HTTPS encrypts data in transit, but it does not guarantee that a website is legitimate.
